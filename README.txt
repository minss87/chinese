전화 중국어 — 설치와 사용


■ 1. Azure Speech 키 만들기 (발음·성조 채점)

  1) portal.azure.com 로그인 (무료 계정 가능, 카드 등록은 요구되지만 청구 안 됨)
  2) "리소스 만들기" → "Speech" 검색 → 만들기
  3) 지역은 Korea Central 을 권장 (한국에서 가장 빠름)
  4) 가격 책정 계층은 Free F0 선택 → 월 5시간 무료
  5) 만들어지면 "키 및 엔드포인트" 화면에서
     - 키 1  (예: 3f9a...)
     - 위치/지역  (예: koreacentral)
     두 가지를 복사

  ※ F0 는 구독당 하나만 만들 수 있습니다.
  ※ 이 앱 사용량으로는 5시간을 넘기기 어렵습니다.
     한 문장 채점이 3~5초이므로 월 3,600회 정도 가능합니다.


■ 2. Gemini 키 만들기 (예문 생성 · 2부 대화)

  aistudio.google.com 에서 API 키 생성. 카드 등록 없음.
  이미 쓰던 키가 있으면 그대로 쓰면 됩니다.


■ 3. GitHub Pages 에 올리기

  마이크는 HTTPS 주소에서만 열립니다. 파일을 직접 열면(file://) 동작하지 않습니다.

  1) github.com 로그인 → 우측 상단 + → New repository
  2) 이름 아무거나 (예: chinese), Public 선택, Create
  3) "uploading an existing file" 클릭
  4) 이 폴더 안의 것을 통째로 끌어다 놓기
     - index.html
     - speech-sdk.js
     - data 폴더
     (README.txt 는 올려도 되고 안 올려도 됩니다)
  5) Commit changes
  6) 저장소 Settings → 좌측 Pages
     Source = Deploy from a branch, Branch = main / (root) → Save
  7) 1~2분 뒤 https://아이디.github.io/chinese/ 주소가 나옵니다

  ※ Public 저장소라 코드는 공개됩니다. 키는 코드에 없고 폰에만 저장되니
     키가 노출되지는 않습니다.


■ 4. 첫 실행

  1) 아이폰 사파리로 위 주소 접속
  2) 하단 "설정" 탭 → Azure 키·지역, Gemini 키 입력 → 각각 저장
  3) "홈" 탭 → 1회차 시작
  4) "꾹 눌러서 말하기" 를 처음 누르면 마이크 권한을 묻습니다 → 허용

  말하는 방식은 왓츠앱 음성메모와 같습니다.
  동그란 버튼을 누른 채로 말하고, 말이 끝나면 손을 떼면 됩니다.

  - 누르면 버튼이 살짝 작아지고, 마이크가 실제로 켜지는 순간
    버튼 둘레에 빨간 링이 그려지기 시작합니다. 링이 보이면 말하세요.
  - 버튼 뒤 붉은 후광은 목소리 크기에 따라 커집니다. 안 움직이면
    마이크가 소리를 못 받고 있는 겁니다.
  - 녹음 앞에 0.5초 여백이 자동으로 붙고, 손을 뗀 뒤에도 0.5초 더
    녹음합니다. 끝음절이 잘리지 않습니다.
  - 링 한 바퀴가 10초입니다. 다 돌면 자동으로 채점합니다.
  - 0.4초보다 짧게 누르면 무시됩니다.


■ 회차 구성

  1부 발음 채점 (예문 5개 + 지난 회차 2개)
     문장을 듣고 따라 말하면 Azure 가 채점합니다.
     종합 / 정확도 / 유창성 / 억양 점수와, 글자별 점수가 나옵니다.
     70점 미만 글자는 빨갛게 표시되고 그 글자의 성조를 알려줍니다.
     80점 이상이면 통과, 그 아래는 복습 목록에 들어갑니다.

  2부 대화 (8턴)
     튜터가 중국어로 묻고 자유롭게 답합니다.
     Azure 가 받아쓰고 Gemini 가 의미가 통했는지 판정합니다.
     질문마다 한국어 힌트가 있고, "모르겠어요" 를 누르면 모범 답이 나옵니다.


■ 성조 채점에 대해

  Azure 는 글자(음절)마다 정확도 점수를 줍니다. 성조를 틀리면 그 글자의
  점수가 떨어지므로 어느 글자가 틀렸는지는 정확히 잡힙니다.
  다만 "2성으로 말해야 하는데 3성으로 말했다" 같은 형태로 알려주지는
  않습니다. 앱은 점수가 낮은 글자 옆에 원래 성조를 표시해 줍니다.

  성조를 명시적으로 진단하는 서비스(SpeechSuper, Chivox 등)도 있지만
  월 최소 사용료가 있어 개인용으로는 Azure 무료 등급이 낫습니다.


■ 문제가 생기면

  "Azure 키 또는 지역이 올바르지 않습니다"
     → 지역은 표시 이름(Korea Central)이 아니라 코드(koreacentral)입니다.

  "마이크 권한이 거부되었습니다"
     → 아이폰 설정 › Safari › 마이크 에서 확인, 또는 주소창 좌측
       아이콘에서 웹사이트 설정 → 마이크 허용

  "소리를 알아듣지 못했습니다"
     → 링이 그려지기 시작한 뒤에 말하세요. 후광이 목소리에 맞춰
       움직이는지도 확인하세요.

  마이크가 아예 안 될 때
     → 모든 화면에 "직접 입력" 칸이 있습니다. 중국어로 타이핑하면
       진행됩니다. 이때는 발음 점수가 나오지 않습니다.

  진도는 이 기기의 브라우저에만 저장됩니다. 사파리 기록을 지우면
  같이 사라집니다.

  업데이트가 반영됐는지 확인하려면
     → 설정 탭 맨 아래 "버전" 을 보세요. 파일을 올린 날짜와 다르면
       사파리 캐시입니다. 주소 끝에 ?v=2 를 붙여 열면 새로 받아옵니다.


■ 예문에 대해

  모든 예문(1,196개)이 연재 스토리 「金老师의 베이징 일기」로 미리
  들어 있습니다. 1–3급 1~12화, 4급 13~36화로 이어지며 홈 화면 맨 위에
  이번 화 제목과 줄거리가 보입니다. 예문 생성에는 Gemini 를 쓰지 않고,
  2부 대화만 이번 화 줄거리를 배경으로 Gemini 가 진행합니다.
  한국어 뜻 앞의 빨간 이름표(류 선생님, 샤오리 등)는 그 문장을 말하는 사람입니다.

■ 듣기 · 읽기 (말할 수 없을 때)

  홈의 파란 「듣기」, 초록 「읽기」 타일. 데이터는 data/listen_read.json (36화, 930문항).
  말하기 예문·아이패드 앱 지문과 겹치지 않는 새 문장이고, 그 화의 줄거리와 어휘로 만들었습니다.
  1–3급 화는 듣기·읽기 각 15개(12화는 12개), 4급 화는 각 12개.

  듣기 — 위챗 음성 메시지·옆에서 들리는 대화. 화면에 원문 없이 소리만.
    보통/느리게, 번호를 누르면 그 문장만 다시.
    문제: 내용 이해(한국어 보기) · 들은 문장 고르기 · 빈칸 · 답장 보내기
  읽기 — 1:1 채팅과 단체방. 소리 없이 읽습니다. 말풍선을 누르면 병음이 보입니다
    (빈칸 음절은 가려짐).
    문제: 내용 이해 · 빈칸 · 답장 보내기
  답장 보내기: 고른 답장이 내 말풍선으로 올라가고 상대가 반응합니다.
    틀리면 그 말풍선에 줄이 그어지고 맞는 답장이 대신 올라갑니다.
  답을 고르면 전체 원문·병음(성조 색)·뜻이 나오고, 말풍선을 누르면 그 문장을 들려줍니다.
  안 푼 것 → 틀린 것 순서로 나오고, 다 맞히면 처음부터 다시 할 수 있습니다.
  목소리는 기기 TTS 입니다. 남자 인물은 남성 목소리(없으면 낮은 음), 학생은 높은 음.

■ 랜덤 대화 (지난 회차 복습)

  홈의 「랜덤 대화」 카드. 완료한 단어가 15개 이상이면 열립니다.
  끝낸 회차 전체에서 6단어를 뽑아 (오래 안 본 것·틀렸던 것·지난번에
  못 쓴 것 우선, 我·他 같은 기초어는 덜) 두 단계로 진행합니다.
  1) 떠올리기 4문장: 한국어만 보고 중국어로 말하기. 밑줄 친 한국어 말을
     누르면 그 부분의 중국어 병음이 위에 뜹니다(시작할 때 Gemini 1번 호출,
     이후 저장). 막히면 「문장 들려주기」. 발음 채점은 그대로.
  2) 회상 대화 8턴: 예문에 가장 많이 나온 인물이 전화해서 "그때 기억나요?"
     위쪽 단어 칩 6개는 내가 말하면 빨갛게 켜집니다.
  결과 화면의 못 쓴 단어는 다음 랜덤 대화에 먼저 나옵니다.
  본 진도에는 영향이 없습니다.

■ 아이패드 쓰기 앱 (write/)

  write/index.html 을 저장소의 write 폴더에 올리면
  https://아이디.github.io/저장소/write/ 로 열립니다.
  data/ 는 회화앱 것을 그대로 쓰고, 읽기 지문은 data/reading_texts.json,
  획순은 data/strokes.json, 획순 그리기 라이브러리는 write/hanzi-writer.min.js 입니다
  (키 필요 없음, 인터넷 없이도 동작).
  아이패드 가로 화면 전용. 사파리에서 열고 홈 화면에 추가하면 전체화면.
  화면은 문서 탭(따라 쓰기·획순·받아쓰기·읽기) + 도구 줄 + 왼쪽 화 목록 + 흰 시트 구조입니다.
  받아쓰기의 본보기와 정답은 손글씨체(楷体, fonts/LXGWWenKai-Regular-subset.woff2, 240KB)로
  보여 줍니다. 따라 쓰기 본보기는 고딕 그대로입니다.
  한글은 프리텐다드(fonts/Pretendard-Regular/Bold.woff2)로 고정했습니다.
  펜·지우개는 쓰는 칸 왼쪽 팔레트 한 곳에만 있습니다(두 손가락 탭, E 키도 그대로).
  세로↔가로를 돌리면 칸 크기를 다시 잡습니다. 쓰던 획은 그대로 남습니다.
  기기 설정의 라이트/다크 모드를 따라갑니다. 오른쪽 위 「테마 자동」 버튼을
  누르면 자동 → 밝게 → 어둡게로 바뀝니다. 기기가 다크인데 화면이 밝게
  나오거나 그 반대일 때 직접 고르면 됩니다.

  따라 쓰기 · 획순 · 받아쓰기 · 읽기 네 가지가 들어 있습니다.

  따라 쓰기
  - 왼쪽에서 화를 고르면 그 화의 한자가 순서대로 나옵니다.
  - 본보기 1칸 + 연습 3칸, 칸마다 본보기가 옅어집니다.
  - 애플펜슬 필압에 따라 굵기가 변합니다. 펜을 쓰면 손가락·손바닥은 무시합니다.
  - 쓰는 칸 오른쪽에 붙어 있는 펜·지우개 아이콘으로 바꿉니다(다른 버튼과 분리).
    지우개는 닿은 획만 지웁니다.
    쓰는 칸을 두 손가락으로 톡 치거나 키보드 E 로도 바뀝니다.
    (애플펜슬 더블탭·스퀴즈는 웹에서 받을 수 없는 신호라 쓰지 못합니다.)
  - 3칸을 다 쓰면 완료로 저장되고, 기본값은 「안 쓴 글자만」입니다.

  획순
  - 왼쪽 칸에서 획이 순서대로 그려지고, 오른쪽 칸에 같은 글자를 씁니다.
  - 획 하나하나를 판정합니다. 순서나 방향이 틀리면 그 획은 그려지지 않고,
    두 번 틀리면 그 획이 잠깐 보입니다.
  - 다 쓰면 완료로 저장되고, 기본값은 「안 쓴 글자만」입니다.
  - 획순 데이터는 data/strokes.json 입니다(1,104자). 획순 모드를 처음 열 때만
    받아서 이후에는 저장된 것을 씁니다.

  받아쓰기
  - 그 화의 문어체 지문 문장을 소리로 들려줍니다. 화면에는 공책 세 줄만 나옵니다.
  - 칸 없이 줄 위에 문장을 이어서 씁니다. 줄마다 흐린 가운데선이 있어 글자
    높이를 맞추기 좋습니다.
  - 「뜻 보기」를 켜면 한국어 뜻이 위에 나옵니다. 소리만으로 어려울 때 씁니다.
  - 펜/지우개 전환은 따라 쓰기와 같습니다.
  - 「정답 보기」를 누르면 아래에 원문과 병음이 나옵니다.
    「본보기 겹치기」를 켜면 정답 문장이 줄 위에 옅게 깔려 크기와 간격을 비교할 수 있습니다.
  - 「글씨 채점」은 공책 사진과 정답을 Gemini 에 보내 자형·줄 맞춤 점수와
    틀리게 쓴 글자, 고칠 점을 받습니다(키가 있을 때).
  - 비교한 뒤 맞음/틀림을 직접 고릅니다. 맞음으로 표시한 문장은 다음에 빠집니다.

  읽기 (문어체 지문 해독)
  - 화마다 문어체 지문이 한 편씩 들어 있습니다(36편, 216문장).
    공지문, 안내문, 복약 안내, 채용 공고, 임대 공고, 짧은 기사, 소개글 등
    중국에서 실제로 마주치는 글입니다. 회화앱의 구어체 예문과는 별개입니다.
  - 먼저 지문 전문을 병음도 뜻도 없이 읽습니다. 급수 밖 한자가 있으면
    「새 글자」 버튼에 병음과 뜻이 들어 있습니다(지문당 최대 4자).
  - 「문제 풀기」를 누르면 문장마다 한국어 뜻 4개 중 고르는 문제 6개와,
    마지막에 이 글이 어떤 종류의 글인지 고르는 문제 1개가 나옵니다.
  - 오답은 같은 지문과 다른 지문에서, 글자가 겹치는 문장으로 뽑습니다.
  - 답을 고른 뒤에야 병음과 뜻, 소리가 나옵니다.
  - 플래시: 문제의 3분의 1쯤에서 문장이 2.5초만 보였다 흐려집니다.
  - 글자를 누르면 노랗게 표시됩니다(형광펜). 지문 화면과 문제 화면 모두에서
    되고, 표시한 글자는 왼쪽 「읽기에서 표시한 글자」에 모여 쓰기 과제가 됩니다.
  - 결과 화면에서 「지문 다시 보기」로 전문으로 돌아갑니다.
  - 회화앱 약점 문장을 고르면 지문 대신 그 문장들로 문제가 나옵니다.

  회화앱에서 발음이 낮았던 문장은 맨 위 「약점」으로 모입니다.
  쓰기에서는 그 문장의 글자, 읽기에서는 그 문장 자체가 나옵니다.
  진도는 회화앱과 따로 갑니다.
